## OmniGraffle 5 Software Box
## Front and Back
Retail box design for OmniGraffle 5 Professional, showing the front and back panels. The design highlights OmniGraffle’s diagramming strengths through technical illustrations, structured layouts, and a restrained green palette. This packaging was used for the boxed retail release of OmniGraffle 5.

### Box Insert (Folding Insert)
Folding box insert for OmniGraffle 5 Professional, designed to sit inside the retail package. The insert extends the visual language of the box with detailed interface imagery, geometric diagrams, and technical precision, reinforcing OmniGraffle’s role as a serious diagramming tool.

## OmniFocus Software Box (Front)
Front cover of the OmniFocus retail software box. The design centers on handwritten index cards and checkmarks to communicate calm, personal task management. This artwork was used for the boxed release of OmniFocus and highlights its focus on reducing stress and helping people prioritize what matters.

## OmniOutliner Software Box Dyeline
Full production dyeline for the OmniOutliner retail software box. This layout shows the complete outside print wrap, including front, back, spine, and warning panel, with measurements, folds, bleeds, and print constraints clearly marked. The dyeline was used to prepare the boxed Mac release for manufacturing.

## OmniWeb Software Box (Front)
Front cover design for the OmniWeb retail software box. The artwork uses a world map and navigation lines to frame OmniWeb as a fast, global browsing tool focused on user control and efficiency. This design was part of the boxed Mac release sold through retail channels.
